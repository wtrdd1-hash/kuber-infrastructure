# v2026.09.16.161 — WDMV exact-main 후보 해석기 수정

## 내부 / GitHub 업데이트

- 원인: `Auto Reconcile Woldeok Moneyverse`가 성공한 `Build Test Candidate` 중 이벤트가 `push`인 실행만 인정했다.
- 앱 브랜치 자동정리기는 최종 `main` 후보를 의도적으로 `workflow_dispatch -f promote=true`로 실행하므로, 실제로 전부 성공한 exact-main 후보가 인프라 reconcile에서 보이지 않았다.
- 수정: 성공한 `push` 또는 `workflow_dispatch` Test Candidate 중 `head_sha`가 현재 앱 `main` SHA와 정확히 같은 실행만 인정한다.
- 안전성: 과거 성공 후보는 선택될 수 없고 PR 후보는 계속 제외하며, 기존 active-PR Test 후보 보존 guard도 유지한다.
- 승격 순서는 그대로다: exact-main 후보 -> 격리 Test manifest -> public exact-SHA/Test DB smoke -> production-ready signal -> Production manifest -> public Production smoke.
