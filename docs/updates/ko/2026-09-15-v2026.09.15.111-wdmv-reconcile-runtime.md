# v2026.09.15.111 — WDMV reconcile 런타임 복구

## 내부/GitHub 업데이트 내역

- 근본 원인: 과거 `Auto Reconcile Woldeok Moneyverse` 작업을 재실행하면 현재 인프라 `main`이 아니라 과거 workflow-run 커밋을 checkout하여, 최신 앱 테스트 후보를 push하는 단계에서 non-fast-forward 오류가 발생했다.
- 추가 원인: Flux 루트 Kustomization과 `wdmv-test` Kustomization이 각각 10분 주기로 동작하지만 앱 운영 릴리스 테스트 게이트는 약 15분만 대기하여, 중첩 Flux 반영이 끝나기 전에 게이트가 실패할 수 있었다.
- 복구: 인프라 `main`을 명시적으로 checkout하고 자동 승격 push 전에 `origin/main`을 rebase하도록 수정했다. 또한 복구 workflow/config가 `main`에 들어올 때 reconcile이 즉시 실행되도록 push 트리거를 추가했다.
- 지연 개선: Flux 루트와 `wdmv-test` reconcile 주기를 10분에서 1분으로 단축했다. GitRepository 조회 주기는 기존 1분을 유지한다.
- 안전 게이트: 동일 SHA 격리 테스트, 백엔드/DB catalog smoke, noindex 확인, production-ready 신호, 운영 GitOps 반영, 공개 운영 smoke는 그대로 fail-closed 방식으로 유지한다.
