# WDMV 테스트 승격 SHA 일치성 — v2026.09.12.9

## 발견 사항
기존 테스트 승격 워크플로우는 백엔드 이미지/소스 SHA만 갱신하고 프론트엔드 candidate label과 신규 테스트 DB 초기화 소스 SHA는 이전 값으로 남겼습니다. 이는 백엔드, 프론트엔드, 마이그레이션 소스, DB 초기화 소스가 하나의 정확한 애플리케이션 커밋을 가리켜야 한다는 스테이징 계약을 위반합니다.

## 변경
- 테스트 승격 시 백엔드와 프론트엔드 candidate label을 함께 갱신합니다.
- 백엔드 마이그레이션 소스 SHA와 PostgreSQL 신규 초기화 소스 SHA를 함께 갱신합니다.
- 테스트 후보 참조 6개가 동일한 40자리 SHA가 아니면 GitOps 검증을 실패시킵니다.

## 검증
병합 전 GitOps 검증 워크플로우와 스테이징 렌더링 검사를 실행합니다.

## 롤백
이 변경을 되돌리면 됩니다. 승격 PR이 병합되고 Flux가 반영하기 전까지 현재 실행 중인 워크로드에는 영향이 없습니다.
